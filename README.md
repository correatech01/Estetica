# ✨ Landing Page — Estética

Landing page desenvolvida para apresentar serviços estéticos, divulgar procedimentos e facilitar o contato entre clientes e a profissional por meio do WhatsApp.

O projeto possui uma identidade visual elegante, com foco na experiência do usuário, organização das informações e apresentação dos serviços e seus respectivos valores.

## 🚀 Funcionalidades

- Apresentação profissional da clínica/profissional.
- Exibição dos serviços estéticos oferecidos.
- Divulgação dos valores de cada procedimento.
- Botão de contato direto pelo WhatsApp.
- Layout responsivo para diferentes tamanhos de tela.
- Interface com identidade visual moderna e elegante.

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação da página.
- CSS3 — estilização e identidade visual.
- JavaScript — interatividade e funcionalidades da página.

## 🎯 Objetivo do projeto

Desenvolver uma landing page comercial, aplicando conhecimentos de desenvolvimento web e criação de interfaces, com foco na apresentação de serviços, experiência do usuário e facilidade de comunicação.

## 📱 Contato pelo WhatsApp

A página possui integração com WhatsApp por meio de um botão de contato, permitindo que os interessados iniciem uma conversa diretamente com a profissional.
